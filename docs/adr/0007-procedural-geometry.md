# ADR-0007 展厅/画框/灯光全部程序化几何，零外部模型

- 状态：Accepted
- 日期：2026-10-05

## 背景
参考仓库的建筑、画框、长椅、雕塑均为 Blender/Sketchfab GLTF（Draco 解码依赖 Google CDN）。

## 决策
- 展厅：BoxGeometry 拼装墙/地/天花/门洞套口/踢脚线，尺寸来自配置常量；四厅同一构造器参数化生成。
- 画框：框条（四边框+厚度盒）+ 卡纸平面 + 画面平面，按比例与尺寸档计算。
- 灯：THREE.SpotLight + 嵌入式灯筒小几何。
- 无 GLTF 模型依赖、无 Draco CDN 依赖。

## 理由
- 布展工具要求墙长/层高/门洞可调，程序化几何改参数即可；换 GLTF 等于重新建模。
- 离线要求与加载性能均受益（整包模型资产 ≈ 0）。
- 画框尺寸系列与原图比例严格对齐，代码生成精度高于建模。

## 备选
- 写实 GLTF 展厅：视觉精致但资产重、不可参数化、离线包体积大。

## 后果
视觉精致度上限低于写实模型；以材质（粗糙度/微反射/灯效）与暗场藏拙策略保证观感。雕塑/长凳等装饰一期不做。
