# ADR-0004 四厅串联全量展 + 厅区加载

- 状态：Accepted
- 日期：2026-10-05

## 背景
作品库 177 张全挂约需 347 延米墙、单厅（约 90 延米/40 幅）无法承载；177 张纹理与射灯阴影同时激活帧率不达标。曾建议"单厅选片制"，老板决策"四厅串联全量展"。

## 决策
- 四个黑盒展厅 H1–H4，按固定动线以门洞走廊串联，单向推荐、允许逆行；每厅约 40–45 幅。
- 厅区加载：纹理与射灯按厅激活——当前厅全激活，相邻厅仅低载（纹理降档/阴影关），远端厅冻结（仅几何占位）；edit 模式下以当前编辑厅为激活中心，鸟瞰总览时强制性能档。
- 厅间过渡：门洞内 2m 暗廊（过渡区），穿越时以黑场 300ms 掩盖加载切换。

## 理由
- 全量作品同时在展，满足"完整摄影展"叙事。
- 分区加载把同屏活跃成本压回单厅量级，帧率目标可守。

## 备选
- 单厅选片制：工程更省、性能更稳，但老板明确要求全量展。

## 后果
- 工程量 +约 1 天（四厅几何、门洞、分区调度、导航）。
- 布展需分厅组织：作品库支持"按厅筛选"；自动初排按入库顺序均分到四厅，之后手动调整。
