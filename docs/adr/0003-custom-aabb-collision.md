# ADR-0003 自研轻量 AABB 碰撞，不引入物理引擎

- 状态：Accepted
- 日期：2026-10-05

## 背景
参考仓库用 use-cannon 做玩家球体与墙/地面的物理模拟。本项目无跳跃、无飞行、无抛掷、无堆叠。

## 决策
walk 模式采用自研碰撞：玩家为俯视半径 0.35m 的圆（2D），墙体/门洞/画框外凸为 AABB 集合，每帧分轴推进并做圆-AABB 推出；垂直恒定贴地（眼高 1.6m）。edit 模式自由相机不参与碰撞（Orbit 限距/限俯仰防止穿地）。

## 理由
- 物理引擎 90% 能力（重力、冲量、堆叠、关节）本项目用不到。
- 分轴圆-AABB 约 150 行纯函数，可 TDD，行为确定性高、无调参黑洞。
- 包体与初始化成本下降。

## 备选
- @react-three/rapier（Rapier WASM）：强大但 2MB+ WASM、网格 collider 构建复杂。

## 后果
只支持轴对齐墙体；斜墙/曲面墙在 ADR 约束下不进入一期空间。
