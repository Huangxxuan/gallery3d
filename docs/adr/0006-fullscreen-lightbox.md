# ADR-0006 点击作品进入全屏 Lightbox（而非相机推近）

- 状态：Accepted
- 日期：2026-10-05

## 背景
walk 模式点击作品需要"看作品全貌/全屏"。两个方向：相机在 3D 内推近到画前；或黑底全屏看图。

## 决策
点击挂位 → 黑底（#000000）全屏 Lightbox：
- 作品完整显示（contain，零裁剪），下方显示标题/作者/拍摄信息（元信息缺失时不显示占位）。
- ← → / A D 键按"当前厅动线顺序"翻看上一幅/下一幅；滚轮缩放 1×–3× 查看细节（可选，一期仅 2 档）。
- Esc / 点击空白：退出并**精确回到点击前的相机位姿与 PointerLock 状态**。
- walk 未锁定指针时（如 Esc 暂停态）点击不触发 Lightbox。

## 理由
- 摄影作品观看要求零透视畸变、无灯光反光，3D 内推近无法保证。
- 黑底全屏是摄影展/图片网站的既定心智，翻幅利于连续阅读整厅作品。

## 备选
- 相机推近：沉浸不中断，但侧视透视与射灯高光破坏画面；两段式（先推后全屏）多一次交互、多半天工作。

## 后果
需要缓存进入前位姿；Lightbox 期间暂停玩家移动与射灯参数变更。
