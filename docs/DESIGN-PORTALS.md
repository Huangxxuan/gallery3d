## 1. 审查结论（先给证据）

### 1.1 门洞越界：确有 3 扇门开进了封闭暗腔

判定方法：对每扇门，要求 `w/2 ≤ at ≤ 墙长 − w/2`，否则门洞会越过所属墙段端部。

| 门 | 所在墙长 | 门洞区间 | 结果 |
|---|---|---|---|
| CW 南墙 / 北墙 | 1.8（横向） | `[0.30, 2.10]` | **东侧 −0.30m 越界** |
| H4 东墙（出口） | 13 | `[-0.30, 2.70]` | **南侧 −0.30m 越界** |
| 其余 8 扇 | — | — | 通过 |

后果不是"看起来差一点"，而是三类可见缺陷：

1. **CW 两侧门洞的东 0.3m 开进了封闭暗腔**：暗廊东墙（x=1.8）从门洞正中穿过，人站在门前能看到一道被墙截断的假门洞；拱环右腿直接埋在暗廊东墙里。
2. **H4 出口门的拱环绕出墙角**：拱环外缘 z 从 14.98 起，而 H4 南角在 15.4 —— 拱环有 0.42m 悬在暗腔里，从出口厅回望能看到"贴在半空"的环腿。
3. 平面图的墙线按 `wallRuns` 夹紧后与拱门几何不同源，图上也对不上。

**修复**（不改拓扑、只改 3 个数）：

- `CW.x1: 1.8 → 2.4` —— 三条暗廊横向净宽统一 2.4m，1.8m 门洞两侧各留 0.3m 墙垛，与 CS/CN 完全同构。
- `H4.E.at: 1.2 → 2.0`（门心 z=17.4）、`EXIT.W/E.at: 4 → 4.8` —— 出口门南侧留 0.5m 墙垛，拱环外缘距墙角 0.18m。
- 动线末段 `z 16.6 → 17.4`，出口致谢字、平面图、SEQUENCE 同步。

### 1.2 门框尺寸：两级净宽是平面拓扑的必然，不是不一致

- 主门/出口净宽 **3.0m**（4 处：入口内外、出口内外）
- 暗廊门净宽 **1.8m**（6 处）

暗廊横向净宽只有 2.4m，**不可能**放 3.0m 门洞。硬要统一，只能把三条暗廊全部加宽 0.6~1.2m，会顶掉厅间 2.4m 的设备夹层、并让暗廊与厅的转角出现 0.4m 深凹龛（更丑）。所以"统一"应该统一在**拱门语言**上，而不是净宽上：

| 维度 | v5 | v6 | 是否统一 |
|---|---|---|---|
| 拱顶净高 | 3.2 | **3.5**（全馆一致） | ✅ |
| 拱环宽 | 0.12 | **0.14** | ✅ |
| 骑缝突出 | 0.02 | **0.02** | ✅ |
| 起拱线 | 1.7 / 2.3 | 2.0 / 2.6（= 拱顶 − 半径） | 由净宽推导，恒等于半圆 |
| 暗廊墙垛 | 0.30 / **−0.30** | **0.30 / 0.30** | ✅ |
| 主门墙垛 | 1.5 | 1.5（入口）/ 0.5（出口 H4 侧） | 受平面限制 |

### 1.3 拱门太矮

v5 拱顶 3.2m / 厅高 5.2m = 61.5%，且暗廊净高只有 3.6m，拱环顶 3.32m 只剩 0.28m 墙，读起来像"挖了个洞"。v6：

- 拱顶 **3.5m**（67%），主门 3.0×3.5 → 宽高比 **1 : 1.17**，最接近真实罗马半圆拱的观感；
- 暗廊净高 **4.0m**，拱环顶 3.64m，上方留 **0.36m** 墙体，拱门有"门楣墙"压住，不再顶天花。

## 2. 三版方案（代码已内置，可现场比对）

> **拍板记录（2026-10-20）**：老板选定 **A · 高拱**为交付口径 —— 预设 `gallery`，拱顶全馆统一 **3.5m**。
> 代码默认档即 `gallery`，交付路径不依赖任何 URL 参数；`?portal=monumental|layered` 保留为 QA 对比开关（零成本、可复现对照），**不属并行旧镜像**。

切换：在 URL 后加 `?portal=gallery` / `?portal=monumental` / `?portal=layered`（默认 `gallery`）。
参数唯一真源：`src/domain/gallery.ts → PORTAL_PRESETS`。

| | **A · 高拱（默认）** | **B · 纪念碑** | **C · 双档分层** |
|---|---|---|---|
| 预设 id | `gallery` | `monumental` | `layered` |
| 主门净高 | 3.50（起拱 2.00） | 3.75（起拱 2.25） | 3.50（起拱 2.00） |
| 暗廊净高 | 3.50（起拱 2.60） | 3.75（起拱 2.85） | 3.15（起拱 2.25） |
| 拱环宽 | 0.14 | 0.16 | 0.14 |
| 拱上留墙（厅 5.2） | 1.70 | 1.45 | 1.70 / 2.05 |
| 暗廊顶余量（4.0） | 0.36 | 0.09 | 0.71 |
| 气质 | 克制、匀质、白盒美术馆 | 仪式感最强，略纪念性 | 主次分明，暗廊更隐 |
| 风险 | 无 | 暗廊 1.8m 宽 → 1:2.08 窄高拱，仰视压迫；拱上只剩 9cm 墙，接近"顶到天花" | 全馆拱顶不再同一标高，与"统一"诉求有出入 |

**推荐 A**，理由：

1. 3.5/5.2 是白盒展厅里"够高但不喧宾夺主"的甜点区；再高，画心 1.65m 与拱顶的比例会失衡，画在墙上显得小。
2. 主门与暗廊门同标高 → 站在厅里一眼能看穿两道拱，纵深被拉长；这是真实美术馆最常用的手法（同标高连续拱廊）。
3. 余量最健康：暗廊拱环之上还有 0.36m 墙，不会出现"拱贴着天花"的廉价感。
4. 不需要动任何平面尺寸，风险最低。

> B 只有在"想要教堂式仪式感"时才选；C 适合以后要做"主展厅 / 次展厅"分级叙事时再启用。

## 3. 施工参数（A 方案）

```
拱门净宽 W        3.00（主门/出口） | 1.80（暗廊门）
半径 r = W/2      1.50 | 0.90
起拱线 y_s        apex − r
拱顶净高 apex     3.50（全馆恒定）
拱环宽 ring       0.14（洞缘外扩，含弧段与两侧直腿）
骑缝突出 proud    0.02（单侧；拱环总厚 = 墙厚 0.20 + 0.04）
拱上封墙          从 y_s 起、沿外弧 r+0.14 封到该墙最高侧天花（厅 5.20 / 门厅 5.00）
暗廊净高          4.00
```

三条硬约束（测试已钉死）：

1. `at − W/2 ≥ 0` 且 `at + W/2 ≤ 墙长` —— 门洞不越界；
2. `at − W/2 − ring ≥ 0` 且 `at + W/2 + ring ≤ 墙长` —— 拱环不绕出墙角；
3. `apex + ring ≤ 本地天花` —— 拱环不穿顶。

### 构造做法（`PortalFrames`）

- **一洞一环**：外轮廓（洞形外扩 ring、落到底板）减内孔（净洞半圆拱），`ExtrudeGeometry` 单 mesh，深度 = 墙厚 + 2×proud，沿墙厚居中。
  单 mesh 的意义：共享墙两侧由不同空间定义时不会出现两根错位的门柱（v4 的"白柱"根因）。
- **拱上封墙**：路径必须"沿外弧开洞"——`moveTo(左顶) → lineTo(左起拱) → absarc(π→0, 顺时针) → lineTo(右顶) → closePath`。先上后横再闭合会产生贯穿对角边，填充区缩水且拱肩漏光（v5 已踩过）。
- **材质**：拱门套 `#43464d / rough 0.6 / metal 0.45` + 程序化 RoomEnvironment 环境反射（无 envmap 时高金属度会渲染成死黑）；拱上封墙用**无板缝纯色** `#ecebe7`，与墙面同色但避开混凝土贴图的板缝十字落在门洞轴线上。
- **碰撞**：拱环与封墙不进 Octree（玩家高度 1.7m，永远碰不到 3.2m 以上），门洞由 `wallBoxes` 全高开口保证可通行。
