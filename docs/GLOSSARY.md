# 术语表（GLOSSARY）

本文件只定义领域语言，不含实现细节。冲突时以此表为准。

| 术语 | 定义 | 边界/备注 |
|---|---|---|
| **作品（Artwork）** | 一张摄影作品原图及其元信息（标题、作者、拍摄信息、文件名） | 不含装裱；作品可以"在库未展"或"在展" |
| **作品库（Library）** | 全部已导入作品的集合（177 张全量） | 与"展览"分离：入库不等于上墙 |
| **展览（Exhibition）** | 一次布展的完整配置：四厅、墙面、挂画、灯光、设置 | 可保存多份；当前编辑的一份为"当前展览" |
| **展厅（Hall）** | 黑盒空间中的一个独立房间单元，全展共四个，按固定动线串联 | 编号 H1–H4；每厅有独立墙面集合与入口/出口门洞 |
| **动线（Route）** | 观众步行经过四厅的单向顺序路径 H1→H2→H3→H4 | 门洞相连；是否允许反向行走由规格定（允许） |
| **墙面（Wall）** | 厅内可挂画的平面（含隔断墙），有编号、朝向与可挂区域 | 窗面/门洞所在墙的可挂区域扣除洞口 |
| **挂位（Slot）** | 墙面上一幅"装裱作品"的安放记录（位置、尺寸档、朝向） | 一幅在展作品在每时刻恰有一个挂位 |
| **装裱（Mount/Frame）** | 作品外的框+卡纸形制，全展统一 A 款，尺寸分 S/M/L | 装裱是挂位属性，不修改作品原图 |
| **画心** | 卡纸开窗内可见的作品画面区域 | 尺寸由原图比例与尺寸档推出，零裁剪 |
| **射灯（Spot）** | 从天花投向单幅作品的聚光单元，目标锁定画心 | 每幅在展作品恰有一盏；随挂位创建/删除 |
| **编辑模式（edit）** | Orbit 鸟瞰视角下的布展操作模式：拖拽、检查器、作品库 | 与 walk 构成唯一模式状态机 |
| **漫游模式（walk）** | PointerLock 第一人称地面行走看展模式 | WASD/方向键移动、鼠标视角、Shift 加速 |
| **全屏看画（Lightbox）** | walk 中点击作品进入的黑底全屏看画状态 | 可左右翻幅；退出回到进入前的相机位 |
| **检查器（Inspector）** | edit 右栏，编辑选中挂位/射灯参数的面板 | 所有拖拽操作在此有数值输入等价通道 |
| **性能档（Perf Mode）** | 标准/性能两档渲染设置（P 键切换） | 性能档关闭射灯阴影 |
| **纹理档（Texture Tier）** | 作品展示纹理的分辨率档位：2048 / 4096（L 档作品） | 原图永不直接送入显存 |
| **厅区加载（Hall Zoning）** | 按玩家/相机所在厅，只激活邻近厅的纹理与灯光的机制 | 保证四厅 177 盏灯场景帧率达标 |
