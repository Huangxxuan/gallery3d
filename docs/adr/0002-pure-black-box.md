# ADR-0002 纯黑盒单光环境，撤销昼夜切换

- 状态：Accepted
- 日期：2026-10-05

## 背景
初版设计为白盒子美术馆默认 + N 键夜场射灯。老板观看样张与用途后选择"纯黑盒沉浸"。

## 决策
展厅恒为炭黑暗场（墙 #161514、地 #232221、天花 #0E0E0E），环境光 0.05；射灯是常态主光源；不实现昼夜切换。

## 理由
- 用途核心之一是"增加灯光以后的效果"，黑盒下灯光效果唯一且显著。
- 彩色旅行纪实作品在深墙+暖白卡纸上浮出感最强。
- 单光环境砍掉一套灯光预设与切换逻辑，约减半天工作量。

## 备选
- 白盒+夜场双模式：白天灯光效果不可见，与核心诉求相悖。

## 后果
无日景布展效果图；若未来需要白盒，以"灯光预设包"形式扩展，不改架构。
