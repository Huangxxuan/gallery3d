# 功能规格：3D 摄影展布展漫游系统

- 版本：v1.0（Phase 1 稿，待审批）
- 日期：2026-10-05
- 遵循：design-system.md v1.0、GLOSSARY.md、ADR-0001~0007

## Problem Statement

作为摄影展操盘手，我手上有 177 张旅行纪实与风光摄影作品（1.06GB），在真实挂画和租场之前，无法直观看到"作品挂到指定位置、加上灯光之后"的整体效果；平面排版和想象无法判断画与画的间距、画心高度、射灯角度、四厅动线是否成立。我需要一个本地运行的 3D 电子展馆：在编辑模式里把作品拖上墙、调灯、调尺寸；在漫游模式里像真实看展一样用鼠标和键盘走进去，点开任何一幅作品全屏看全貌。

## Solution

一个 Vite + React + Three.js（r3f）的本地 Web 应用。编辑模式提供暗色三栏工作区：作品库（四厅全量 177 张）→ 3D 黑盒展厅画布（Orbit 鸟瞰 + TransformGizmo 拖拽）→ 检查器（位置/尺寸/射灯数值）。漫游模式进入 PointerLock 第一人称地面行走（WASD/方向键，鼠标视角，Shift 加速，碰撞不穿墙）。四个黑盒展厅串联承载全量作品，按厅分区加载保帧率。点击作品进入黑底全屏 Lightbox 翻看整厅作品。全部布展数据由一份 JSON Schema 描述，localStorage 自动保存、可导入导出。

## User Stories

### 导入与作品库
1. 作为操盘手，我想把 `摄影作品` 目录的 177 张照片（JPG/HEIC）批量导入作品库，这样一次建立全量作品资产。
2. 作为操盘手，我想导入时自动读取像素宽高、按比例归入六类标准比例或标记"非标"，这样装框零裁剪。
3. 作为操盘手，我想导入时自动生成 2048px 展示纹理（L 档作品 4096），这样 1GB 原图不会撑爆显存。
4. 作为操盘手，我想作品库显示缩略图、文件名、比例标记、所属厅/在展状态，这样我能快速找作品。
5. 作为操盘手，我想按厅、按比例、按关键字（文件名）筛选作品库。
6. 作为操盘手，我想单张补传照片并自动入库，不影响已有挂位。
7. 作为操盘手，我想 HEIC 能正常显示（自动转码为浏览器可渲染纹理）。

### 编辑布展
8. 作为操盘手，我想从作品库把作品拖到某面墙的任意位置，松手即挂上并自动生成装裱与射灯。
9. 作为操盘手，我想拖拽时作品自动吸附到墙面平面（不能拖离墙、不能倾斜嵌入墙）。
10. 作为操盘手，我想沿墙拖动时有 0.6m 最小中缝的实时提示（绿色可放/红色冲突）。
11. 作为操盘手，我想在检查器用数值输入框精确设置位置、尺寸档（S/M/L），键盘 ↑↓ 步进（Shift ×10），这样鼠标不是唯一手段。
12. 作为操盘手，我想选中作品后看到 TransformGizmo 与黄铜高亮框，明确当前操作对象。
13. 作为操盘手，我想删除挂位时同步删除其射灯，作品回到库中"未展"状态。
14. 作为操盘手，我想一键自动初排：作品按入库顺序均分到四厅、按墙面自动排列（画心 1.50m、中缝 0.6m），得到可改的基线。
15. 作为操盘手，我想把作品从一面墙移到另一面墙、跨厅移动，并自动重算射灯。
16. 作为操盘手，我想在四厅之间切换编辑视角（鸟瞰总览 / 进入某厅编辑）。
17. 作为操盘手，我想撤销/重做（Ctrl+Z / Ctrl+Shift+Z）最近 50 步布展操作。
18. 作为操盘手，我想看到每厅已挂数量与墙面利用率，判断是否超载（单厅上限 45 幅）。
19. 作为操盘手，我想非标比例作品自动按原比例装框，不出现拉伸或裁剪。

### 灯光
20. 作为操盘手，我想每幅作品自动获得一盏射灯，灯头 30° 俯角、目标锁画心、光斑覆盖卡纸外径 +10cm。
21. 作为操盘手，我想在检查器实时调节射灯强度（0.5–3.0）、角度、半影、色温（仅 3000–4500K 白暖区间），3D 画面即时反馈。
22. 作为操盘手，我想开关单盏射灯对比效果，并一键恢复默认参数。
23. 作为操盘手，我想展厅只有环境微光与入口洗墙光，作品是唯一高亮区域。
24. 作为操盘手，我想射灯没有彩色模式，保证摄影作品无色偏。

### 视角与漫游
25. 作为操盘手，我想在顶栏一键切换 edit/walk，切换时视角零跳变（位姿互相初始化 + 300ms 黑场）。
26. 作为观众，我想用 WASD 或方向键地面行走、鼠标控制视角、Shift 加速。
27. 作为观众，我想走到墙边/画前会被挡住，不能穿墙穿画穿框。
28. 作为观众，我想穿过门洞进入下一厅，暗廊过渡自然不卡顿，逆行也可以。
29. 作为观众，我想随时 Esc 释放鼠标，屏幕出现操作说明与"点击继续游览"。
30. 作为观众，我想在四厅中始终知道自己在哪（HUD 厅名/序号），编辑态可开小地图（漫游态默认隐藏）。
31. 作为观众，我想 P 键切换性能档，低性能设备关掉射灯阴影仍可看展。

### 全屏看画
32. 作为观众，我想在 walk 中点击作品，进入黑底全屏看到作品完整全貌（contain 零裁剪）。
33. 作为观众，我想在 Lightbox 看到标题/作者/拍摄信息（没有则不显示空字段）。
34. 作为观众，我想 ←→（或 A/D）按本厅动线顺序翻看作品。
35. 作为观众，我想滚轮在 1×–2× 间缩放查看细节。
36. 作为观众，我想 Esc/点击空白退出全屏，回到点击前站立的精确位置与视角。

### 保存与交付
37. 作为操盘手，我想所有布展改动 500ms 内自动保存，刷新页面后原样恢复。
38. 作为操盘手，我想导出整个展览为 JSON 文件，并在另一台电脑导入还原。
39. 作为操盘手，我想导入配置时有 Schema 校验，坏配置给出具体字段错误而不是白屏。
40. 作为操盘手，我想执行 `npm run dev` 本地访问、`npm run build` 得到可离线打开的 dist 静态包（断网可用，字体/three 全本地）。
41. 作为操盘手，我想在 1920×1080 单厅满载下标准档 ≥45fps、性能档 ≥30fps。

## Implementation Decisions

- 模块划分（不绑定具体文件名）：
  - **展览状态核心**：zustand store，形状与 exhibition.schema.json 一一对应；布展操作走 action（挂/摘/移/改灯/改尺寸/分厅），天然支持撤销重做。
  - **布局数学（纯函数）**：比例归类、装裱外径计算、M/S/L 推算、贴墙吸附投影、边界 clamp、中缝冲突检测、自动初排。
  - **碰撞（纯函数）**：圆-AABB 分轴推进，墙体/洞口/画框外凸由厅配置生成 AABB 表。
  - **3D 场景**：程序化展厅构造器（四厅+门洞暗廊）、地面（微反射）、雾、装裱组件（框/卡纸/画面）、射灯组件、玩家控制器、相机切换 RIG、厅区加载调度器。
  - **编辑器 UI**：顶栏/作品库/检查器/状态条/小地图，拖拽与数值双通道写同一 action。
  - **Lightbox**：独立 DOM 层（非 3D 内），contain 看图、翻幅顺序由当前厅挂位动线生成。
  - **资产管线**：导入时读尺寸 → 生成纹理档 → HEIC 转码 → 缩略图；素材复制到 public/photos，配置存相对路径。
  - **持久化**：localStorage 自动保存 + JSON 导入导出 + schemaVersion 迁移。
- 交互约束：贴墙只允许"沿墙面平移 + 垂直高度调整"，不允许自由旋转画框（旋转仅 0/90/180/270 吸附，适配横竖向；一期仅保留与原朝向一致的两种，旋转功能本身在范围但默认禁用 UI，归入二期开关——见 Out of Scope 裁决：一期不提供旋转 UI）。
- 键盘：edit 下快捷键（1 选/2 移/3 灯、Del 摘画、Ctrl+Z/Y、F 居中、H1–H4 切厅）；walk 下 WASD/方向键/Shift/P/Esc。

## Testing Decisions

- 测试只验外部行为，不断言内部实现。最高接缝策略：
  1. **纯函数单测（最高价值，TDD 主区）**：布局数学与碰撞零 DOM/WebGL 依赖，覆盖：六比例归类、非标比例装裱尺寸、贴墙吸附与边界、中缝冲突、圆-AABB 推出（含门洞可通过、画框阻挡）、Schema 校验与版本迁移、动线翻幅顺序。
  2. **store 行为测试**：挂/摘/移/撤销重做/自动初排后的状态断言。
  3. **端到端（Playwright，少量关键流）**：导入样例 8 张 → 自动初排 → 拖一幅改位置并数值校验 → 切 walk → 行走过厅 → 点开 Lightbox 翻幅退出 → 刷新恢复。
- 不做：3D 像素级快照、渲染内部断言、r3f 组件实现细节 mock。

## Out of Scope（一期明确不做）

- 白盒/昼夜多光环境（ADR-0002）。
- 画框多形制切换、卡纸多色切换（全展统一 A 款暖白）。
- 挂画自由旋转/斜挂（一期仅正挂）。
- GLTF 写实模型、雕塑长椅装饰（ADR-0007）。
- 飞行/跳跃（纯地面行走）。
- VR/移动端触控适配、多人联机、云端同步、在线发布。
- 实体打印尺寸/装裱报价/物流。
- 作品在线编辑（调色裁切）；原图管理仅限导入与纹理档生成。
- 可视化小地图在漫游态默认开启（仅编辑态 + 可选开关）。
